# 腾讯 EdgeOne 部署（Makers 边缘函数 + EdgeOne KV）

这里用的是 **KV 键值存储**，不需要 MySQL。数据和 Cloudflare D1 版本内容一致，
只是底层换成 KV，API 返回格式完全相同，客户端不用改代码。

## 控制台步骤

1. EdgeOne 控制台 → **Makers → 存储 → KV 存储** → 申请开通 → 新建命名空间，例如 `fangdong`。
2. **边缘函数 → 函数管理 → 新建函数**，把 `dist/index.js` 的内容整体粘贴进去，触发方式选“处理所有请求”。
3. 函数详情 → **拓展服务 / 服务绑定 → 新增服务绑定**，选择上一步的 KV 命名空间，**变量名填 `my_kv`**
   （代码默认读 `my_kv`；若你换了变量名，改 `dist/index.js` 顶部的 `KV_BIND` 那一行，或配置环境变量 `KV`）。
4. 绑定域名 / 路由后，访问 `https://你的域名/api/health`，返回
   `{"code":0,"data":{"platform":"edgeone"...}}` 即部署成功。

## 客户端怎么填

App / PC 端“云端同步”里的服务端地址填：`https://你的域名/api`

## 注意

- KV 是**最终一致**：跨节点最长 60 秒才同步，个人记账场景没问题；
- 单条 value 上限 25 MB，账单 JSON 远小于此；
- 免费版 KV 容量 1 GB，够存几万条账单。

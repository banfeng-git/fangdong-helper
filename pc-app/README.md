# 房东小助手 · 电脑版（独立的桌面程序）

这是**真正的桌面应用**（Java Swing 窗口程序），不是浏览器打开的网页，
也不需要装浏览器插件。双击 `启动-Windows.bat` 就能用。

## 直接运行

| 系统 | 怎么启动 |
| --- | --- |
| Windows | 双击 `启动-Windows.bat` |
| macOS / Linux | 双击或命令行执行 `./启动-Mac-Linux.sh` |

前提：电脑装了 Java 11 以上（推荐 Java 17）。Windows 如果没装，
脚本会提示下载地址。

## 打包成 exe（可选）

在 Windows 上装好 JDK 17，双击 `build-exe.bat`，会用官方 `jpackage`
生成带开始菜单快捷方式和桌面图标的 `.exe` 安装包。

## 功能

- 房间管理、账单管理（水表/电表/燃气表都支持多块，起止码自动算用量和费用）
- 其他收费：固定金额（卫生费、网费等）或按用量
- 一键生成账单表格图片（与手机 App v2.9/v2.10 版式、规则完全一致）
- 一键复制分享文本（含起止码）
- 下月账单：止码自动变成起码
- 云端同步（可选）：填任意一家自建后端地址，注册/登录后可上传、下载账单

## 数据存在哪

`用户目录/.fangdong-helper/data.json`（Windows 在 `C:\Users\你的用户名\.fangdong-helper\`），
生成的图片在 `用户目录/.fangdong-helper/账单图片/`。

备份直接复制这个文件夹即可。
